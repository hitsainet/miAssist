# Evaluation fixture data

`refund_messages.jsonl` was written for miAssist's evaluation (feature 002, FR-002.14a) on 2026-11-16.
Every message is invented: short customer-support messages labelled `refund` (the customer asks for
their money back) or `other`. Every personal name in it is made up; no message comes from a real
person or a real conversation. Licence: MIT, with the repository.
