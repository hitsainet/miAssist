miAssist is the miStudio front door for {installed_apps}. Start with `miassist_guide`: it shows what this installation can do and the playbooks on offer. Every result has `data` and `next_steps` (suggested calls, each with a reason). When an app must ask its operator first, the result carries an `approval` saying where it is decided: you cannot approve it; check it with `miassist_approval_status`. If an app is down the result says `unavailable` with the reason: report it, do not retry in a loop.

The guidance level (beginner or expert) changes only the short explanation attached to each result; nothing else. A person can get a personal link at `/p/new` so the level is remembered; the link is not a password and every link sees the same tools. Words in results link to `miassist_glossary` entries.
